# فاحص بيانات الطلاب

موقع يفحص Google Sheets ويعرض اسم الطالب وأسماء الأعمدة التي تحتوي على خانات فارغة.

## الإعداد
1. افتح ملف Google Sheets الذي يحتوي على بيانات الطلاب.
2. من Extensions اختر Apps Script.
3. ضع كود Code.gs في ملف Code.gs.
4. أضف ملف HTML باسم Index والصق محتوى Index.html.
5. احفظ ثم اختر Deploy > New deployment > Web app.
6. اختر Execute as: Me، وWho has access: Only myself.
7. افتح رابط التطبيق المنشور.

## تنسيق الشيت
- الصف الأول: ترقيم (يتم تجاهله).
- الصف الثاني: أسماء الأعمدة.
- الصف الثالث وما بعده: بيانات الطلاب.
- يفحص التطبيق أول تبويب في الملف.

تنبيه: لا تضع بيانات طلاب حقيقية أو أسرارًا في هذا المستودع العام. رفع الملفات إلى GitHub لا ينشر تطبيق الويب تلقائيًا.
